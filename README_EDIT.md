# ASW Portfolio Editable V2

Buka `index.html`.

Klik tombol **✎ Edit Portfolio** di kiri bawah.
Isi nama, headline, deskripsi, WhatsApp, email, dan judul project.
Klik **Simpan Perubahan** untuk melihat perubahan langsung.
Klik **Download Website Terbaru** untuk membuat file HTML terbaru.

Catatan:
- Perubahan yang disimpan tersimpan di browser (localStorage).
- Untuk website online, upload file HTML terbaru ke GitHub Pages.
- Ganti data fiktif dengan data portfolio kamu sendiri.
